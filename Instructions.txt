==========================================================
1. PROJECT VISION
==========================================================

Cyberjourney is a cybersecurity learning platform that teaches
users from beginner level to advanced level through
interactive games, simulations, and challenges.

The platform is divided into three connected experiences:

1. Cyber Academy
2. CyberOps Lab
3. Cipher Escape


The user grows from a beginner learner into an advanced
cybersecurity problem solver.


==========================================================
2. LEARNING PATH
==========================================================


LEVEL 1

Cyber Academy

Difficulty:
Beginner


Goal:

Teach basic cybersecurity awareness.


User learns:

- Password security
- Phishing detection
- Safe browsing
- Malware awareness
- Device security
- Basic networking



        ↓



LEVEL 2

CyberOps Lab

Difficulty:
Intermediate


Goal:

Teach how cybersecurity professionals investigate threats.


User learns:

- Security logs
- Network analysis
- Malware investigation
- Digital forensics
- Incident response
- Security tools



        ↓



LEVEL 3

Cipher Escape

Difficulty:
Advanced


Goal:

Challenge users with advanced cybersecurity puzzles.


User learns:

- Cryptography
- Encoding
- Encryption concepts
- Cipher solving
- Security problem solving

11. PROJECT DEVELOPMENT RULES
==========================================================


Rule 1:

Finish one project before starting another.


Rule 2:

Make every project playable before adding advanced features.


Rule 3:

Reuse common systems between projects.


Rule 4:

Keep beginner users and advanced users separate.


Rule 5:

Focus on learning experience, not only features.
