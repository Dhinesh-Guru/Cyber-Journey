==========================================================
             CYBER ACADEMY PROJECT ROADMAP
==========================================================

Project Name:
Cyber Academy - Learn Cybersecurity Through Games

Project Type:
Educational Cybersecurity Game

Difficulty:
Beginner Friendly

Main Idea:
--------------
Create a game where beginners learn cybersecurity through
quizzes, mini-games, and a virtual laptop simulator.

The player becomes a cyber trainee and completes missions
to become a Cyber Defender.

==========================================================
1. MAIN GAME FLOW
==========================================================

Player starts as:

Cyber Trainee

↓

Complete lessons

↓

Answer quizzes

↓

Play mini-games

↓

Complete laptop missions

↓

Earn XP and badges

↓

Rank up

↓

Become Cyber Defender


==========================================================
2. GAME STRUCTURE
==========================================================

The game has 3 main parts:

1. Learning Section
2. Mini Games
3. Virtual Laptop Simulator


==========================================================
3. LEARNING SECTION
==========================================================

Each topic starts with a short explanation.

Example:

Topic:
Strong Passwords

Learn:

- Why passwords are important
- What makes a password weak
- How hackers guess passwords
- Why MFA is useful


After learning:

Player takes a quiz.


==========================================================
4. QUIZ SYSTEM (MCQ)
==========================================================

Purpose:

Test player's understanding.


Features:

- Multiple choice questions
- Explanation after answer
- Score system
- Difficulty levels


Example:


Question:

Which password is strongest?


A) password123

B) john2005

C) T!ger#92Moon


Answer:

C


After answer:

Explain why it is better.
