==========================================================
                CIPHER ESCAPE - PROJECT GUIDE
==========================================================

Project Type:
-------------
Puzzle / Escape Room / Cryptography Game

Difficulty:
-----------
Intermediate → Advanced

Goal:
-----
Build a story-driven puzzle game where players escape rooms by solving
different encryption, decoding, and logic puzzles.

==========================================================
1. CORE GAMEPLAY
==========================================================

Player enters a room
        ↓
Reads story or mission
        ↓
Solves puzzle
        ↓
Door unlocks
        ↓
Collect reward
        ↓
Move to next room

Each room should feel unique.

==========================================================
2. STORY MODE
==========================================================

Example Story

"You wake up inside an abandoned cyber security laboratory.
Every door is locked.
The only way to escape is by solving encrypted messages left
by an unknown hacker."

Create multiple chapters.

Example:

Chapter 1
---------

Chapter 2
---------
Security Office

Chapter 3
---------

Chapter 4
---------

==========================================================
5. DIFFICULTY SYSTEM
==========================================================

Easy

• Simple ciphers
• Unlimited time

Medium

• Less hints
• Time limit

Hard

• Multiple encryption layers

Expert

• No hints
• Randomized puzzles
• Hidden clues

6. HINT SYSTEM
==========================================================

Hint 2
-------
Provides clue
