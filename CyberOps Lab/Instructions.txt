==========================================================
              CYBEROPS LAB PROJECT ROADMAP
==========================================================

Project Name:
CyberOps Lab - Security Analyst Training Simulator


Project Type:
Intermediate Cybersecurity Learning Game


Difficulty:
Intermediate


Purpose:
--------------
A game that teaches players how cybersecurity defenders
investigate, analyze, and respond to security incidents.

This project connects beginner cybersecurity knowledge with
advanced cryptography and security challenges.


==========================================================
1. STORY
==========================================================

The player has completed Cyber Academy and joins a Security
Operations Center (SOC) as a Junior Security Analyst.

Their job:

- Investigate suspicious activities
- Analyze security events
- Find threats
- Protect systems


Player Rank:

Level 1:
Junior Analyst

↓

Level 5:
Security Analyst

↓

Level 10:
Threat Hunter

==========================================================
3. CORE MODULES
==========================================================


MODULE 1:
LOG INVESTIGATION


Goal:

Teach players how security events are recorded.


Player learns:

- Login events
- Failed attempts
- User activity
- Suspicious behavior


Example:


System Log:

10:00 Login successful

10:01 Login failed

10:02 Login failed

10:03 Login failed

10:04 Admin login from another country


Question:

What happened?


Answer:

Possible brute force attack



==========================================================
MODULE 2:
PASSWORD SECURITY ANALYSIS
==========================================================


Goal:

Understand how attackers target weak passwords.


Learn:

- Password strength
- Brute force attacks
- Dictionary attacks
- Password hashing


Game:


Compare:


Password A:

hello123


Password B:

T!ger#92Moon


Player predicts which is safer.



==========================================================
MODULE 3:
HASH DETECTIVE
==========================================================


Goal:

Learn hashing concepts.


Topics:

- Hash functions
- File integrity
- Password hashes


Example:


File A Hash:

8f14e45f


File B Hash:

8f14e45f


Question:

Are files identical?


Answer:

Yes
